# Gen-Z Love Website

This is a fully editable, mobile-friendly romantic website. It uses plain HTML, CSS, and JavaScript—no installation or coding tools required.

## Customize it

Open `index.html` in any editor and use the `CUSTOMIZE:` comments as your guide.

1. Replace every `her name` and `your name`.
2. Change the timeline dates and stories.
3. Replace the image URLs with your own photos. You can place photos in a `photos` folder and use paths such as `photos/our-first-date.jpg`.
4. Add your music file beside `index.html`, then change the empty audio source to `src="our-song.mp3"`.
5. Edit the letter and the little relationship facts to make it personal.

## Open it on your computer

Double-click `index.html`. If your browser does not allow local pages, run a simple local preview (such as VS Code’s Live Server) or publish it using the instructions below.

## Publish free with GitHub Pages

1. Create a GitHub account at [github.com](https://github.com) if you do not already have one.
2. Click the **+** icon in the top-right corner, then choose **New repository**.
3. Give it a name such as `our-story`, leave it **Public**, and click **Create repository**.
4. On the repository page, choose **Add file → Upload files**.
5. Upload everything inside this `genz-love-site` folder: `index.html`, `styles.css`, `script.js`, and any photo/music folders you added. Click **Commit changes**.
6. Open the repository’s **Settings** tab, then select **Pages** in the left sidebar.
7. Under **Build and deployment**, set **Source** to **Deploy from a branch**. Choose branch `main` and folder `/ (root)`, then click **Save**.
8. Wait a minute or two. Refresh the Pages screen—GitHub will show your public website link. Copy it and send it to her.

Whenever you change files, upload the newer versions to the same repository. GitHub Pages updates the live site automatically after a short wait.
